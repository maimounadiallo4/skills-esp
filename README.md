# Utilitaires

Description du projet :
Une collection de skills et de scripts conçus pour améliorer la productivité académique, la prise de notes, l'organisation du contenu et la transcription automatisée. Le dépôt aide à transformer des contenus générés par l'IA en documents plus professionnels, à structurer des notes pour Notion ou Obsidian, et à automatiser la transcription audio/vidéo avec Whisper.

Tags du projet :
